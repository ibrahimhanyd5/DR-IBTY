# استوديو المطبوعات (نسخة GitHub Pages)

موقع جاهز يعمل بدون أي تثبيت أو أوامر. ارفعه على GitHub مرة واحدة، فيصير لديك رابط تعطيه لأي شخص.

## الرفع (5 دقائق، من المتصفح فقط)
1. ادخل github.com وسجّل الدخول، ثم اضغط **New repository**.
2. اكتب اسماً مثل `print-studio`، واختر **Public**، ثم **Create repository**.
3. اضغط **uploading an existing file**، ثم اسحب **كل محتويات هذا المجلد** (الملفات والمجلد `src`) إلى الصفحة، واضغط **Commit changes**.
4. اذهب إلى **Settings ثم Pages**. تحت Source اختر **Deploy from a branch**، ثم Branch: `main` والمجلد `/ (root)`، ثم **Save**.
5. بعد دقيقة أو دقيقتين يظهر الرابط في نفس الصفحة بالشكل: `https://اسمك.github.io/print-studio/`

أرسل الرابط لأي شخص. على الهاتف يمكنه اختيار **إضافة إلى الشاشة الرئيسية** ليعمل كأنه تطبيق.

## التعديل لاحقاً
افتح أي ملف داخل `src` على GitHub، واضغط أيقونة القلم، عدّل، ثم Commit. يتحدث الموقع تلقائياً.

## ملاحظات
- أول فتح يحتاج إنترنت وبضع ثوانٍ (يحمّل المكتبات ويجهّز الكود)، وما بعده أسرع.
- المشاريع تُحفظ داخل متصفح كل مستخدم فقط (ليست مشتركة بين الناس).
- لا يوجد خادم ولا مفاتيح سرية.

## إذا ظهر خطأ «تعذر تحميل src/App.tsx (404)»
معناه أن المجلد `src` لم يُرفع. تأكد أن في المستودع مجلداً اسمه `src` وفيه الملفات. وإن واجهتك صعوبة في رفع المجلد، استخدم الحل الأسهل: ارفع الملف المنفرد `index.html` من مجلد `single-file` (بدل كل الملفات)، فيعمل الموقع بملف واحد فقط.
